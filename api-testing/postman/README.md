# Postman API Tests

This directory contains an exported Postman collection demonstrating REST API testing using JSONPlaceholder.

## Covered Operations

- GET all posts
- GET a single post
- POST / Create
- PUT / Update
- DELETE

## Automated Validations

The collection includes automated Postman tests for:

- HTTP status codes
- Response data types
- Required JSON properties
- Resource IDs
- Response content validation
- Create and update response validation

## API

JSONPlaceholder  
https://jsonplaceholder.typicode.com/

## Notes

JSONPlaceholder is a fake REST API designed for testing and prototyping.

POST, PUT, and DELETE requests are simulated and do not permanently modify the server data.
