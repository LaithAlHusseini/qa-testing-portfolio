# QA Testing Portfolio

[![Playwright Tests](https://github.com/LaithAlHusseini/qa-testing-portfolio/actions/workflows/playwright.yml/badge.svg)](https://github.com/LaithAlHusseini/qa-testing-portfolio/actions/workflows/playwright.yml)

A practical software quality assurance portfolio demonstrating manual testing, test design, defect reporting, API testing, and test automation.

## Objectives

This repository documents my hands-on learning and practice in Software Quality Assurance.

It focuses on applying testing principles to realistic software scenarios rather than only studying testing theory.

## Areas Covered

- Requirements Analysis
- Test Scenario Design
- Test Case Design
- Positive & Negative Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Exploratory Testing
- Defect Reporting
- API Testing
- Test Automation

## Tools

The portfolio will progressively include:

- Postman
- Playwright
- Git & GitHub
- GitHub Actions

## Repository Structure

### Manual Testing
Test scenarios, test cases, and exploratory testing documentation.

### Bug Reports
Structured defect reports containing severity, priority, reproduction steps, expected results, and actual results.

### API Testing
REST API testing and Postman collections.

### Automation
Automated UI and API tests using Playwright.
